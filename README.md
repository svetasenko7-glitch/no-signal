# NO SIGNAL

Веб-синтезатор помех и глитчей с использованием Tone.js.
Арт-практика, дизайн-программирование ВШЭ, 2 курс, модуль 1.

**Оператор старого телевизора: поймай сигнал в эфире — потеряй — найди снова.**

---

## Как играть

На старте всё выключено, звук включается кнопкой **PLAY**.

| Объект                                              | Действие | Что происходит                              |
| --------------------------------------------------- | -------- | ------------------------------------------- |
| **PLAY** ▶                                          | click    | запускает секвенсор                         |
| **STATIONS** AM / FM / NOISE                        | click    | меняет характер звука: темп, волну, эффекты |
| **Шаги AIR / NOISE**                                | click    | включает или выключает шаг в паттерне       |
| **DRONE**                                           | click    | фоновый гул C2 + C3                         |
| **PROPHYLAXIS**                                     | click    | телевизионный писк + шум эфира              |
| **GLITCH**                                          | click    | мгновенный сбой всех параметров на 0.5 сек  |
| **Ручки** BITS / FILTER / DELAY / DIST / WAH / FDBK | drag ↕   | меняет параметр эффекта                     |
| **VOLUME**                                          | drag ↔   | громкость голоса                            |
| **TEMPO**                                           | drag ↔   | скорость секвенсора (60–180 BPM)            |

---

## Устройство звука

В инструменте два голоса. Цепочки перечислены по порядку, каждая заканчивается своим каналом.

| Голос     | Цепочка                                                                    |
| --------- | -------------------------------------------------------------------------- |
| **AIR**   | Synth + Noise, BitCrusher, AutoFilter, PingPongDelay                       |
| **NOISE** | NoiseSynth + MetalSynth + AmbientNoise, Distortion, AutoWah, FeedbackDelay |

Голоса разведены по каналам: AIR — влево, NOISE — вправо.

8 шагов секвенсора в каждой строке. AIR играет ноты, NOISE — удары шума и металла. Клик по шагу добавляет или убирает ноту.

### Три станции

|          | AM             | FM                   | NOISE       |
| -------- | -------------- | -------------------- | ----------- |
| Характер | тёплый, мягкий | металлический, яркий | хаос, глитч |
| Волна    | sine           | square               | square      |
| Темп     | 90             | 120                  | 160         |
| DIST     | 0.3            | 0.6                  | 0.9         |
| FILTER   | 0.5            | 3                    | 8           |

Каждая станция — отдельный сет.

## В работе использован DeepSeek

- подбор параметров синтезаторов Tone.Synth, NoiseSynth, MetalSynth
- сборка и настройка цепочек эффектов
- разведение голосов по каналам через Tone.Channel
- логика динамического обновления секвенсора
- структура кода: модули по голосам, отдельный файл обработчиков
- отладка: запуск аудио-контекста, порядок инициализации, полная остановка звуков

Концепция, визуальный дизайн, интерфейс, HTML/CSS-вёрстка и интерактивные механики выполнены без нейросетей.
